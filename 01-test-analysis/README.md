# Тест-анализ: классы эквивалентности и граничные значения

## Описание
Проведён тест-анализ требований на валидацию полей формы Яндекс Маршрутов. Определены классы эквивалентности и граничные значения для каждого поля.

## Что анализировалось
- **Время начала поездки. Часы** — допустимый диапазон, недопустимые значения, типы данных
- **Время начала поездки. Минуты** — допустимый диапазон, недопустимые значения, типы данных
- **Поле ввода адреса «Откуда»** — адреса из списка, невалидные адреса, пробелы
- **Поле ввода адреса «Куда»** — адреса из списка, невалидные адреса, пробелы
- **Расстояние между адресами** — адреса из матрицы, равное 0
- **Время начала движения** — интервалы времени и средняя скорость
