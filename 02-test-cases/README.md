# Тест-кейсы

## Описание
Создан набор тест-кейсов на проверку валидации полей формы Яндекс Маршрутов и расчёт времени/стоимости поездки на собственном автомобиле.

## Что проверялось
- Поле «Часы» — валидные и невалидные значения
- Поле «Минуты» — валидные и невалидные значения
- Поле «Откуда» — валидные и невалидные адреса
- Поле «Куда» — валидные и невалидные адреса
- Расчёт времени и стоимости поездки на своём автомобиле

## Техники тест-дизайна
- Классы эквивалентности
- Граничные значения

## Инструменты
- Google Таблицы
- Тестовый стенд Яндекс Маршрутов

## Результат
- Составлено 65 тест-кейсов
- Passed: 41
- Failed: 24
- Заведены баг-репорты по найденным дефектам
