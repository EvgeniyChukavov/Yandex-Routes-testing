# Тестирование веб-приложения Яндекс Маршруты

## О проекте
Проведено тестирование веб-приложения Яндекс Маршруты: валидация полей формы и расчёт стоимости/времени поездки на собственном автомобиле.

**Яндекс Маршруты** — это сервис, который строит маршруты для транспорта разных видов, рассчитывает время и стоимость поездки.

## Что тестировалось
- Валидация полей ввода: «Часы», «Минуты», «Откуда», «Куда»
- Расчёт времени поездки на собственном автомобиле
- Расчёт стоимости поездки на собственном автомобиле

## Техники тест-дизайна
- Классы эквивалентности
- Граничные значения

## Инструменты
- Тестовый стенд: https://qa-routes.praktikum-services.ru/
- Google Таблицы — ведение тест-кейсов и баг-репортов
